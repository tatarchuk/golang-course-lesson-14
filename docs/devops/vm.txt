# Why deploy/vagrant/port_check_fix.rb exists. The first `vagrant up` stopped with "The forwarded port to
# 8080 is already in use on the host machine" although nothing listened on 8080. Vagrant 2.4.9 probes a
# host port with Socket.tcp(host, port, connect_timeout: 0.1); on macOS 27 that non-blocking connect
# reports a refused connection as a success, so every port (even SSH 2222) looked taken.

$ nc -z -v -G 2 127.0.0.1 9
nc: connectx to 127.0.0.1 port 9 (tcp) failed: Connection refused
$ /opt/vagrant/embedded/bin/ruby -rsocket -e 'Socket.tcp("127.0.0.1", 9, connect_timeout: 0.1).close; puts "connected"'
connected
$ /opt/vagrant/embedded/bin/ruby -I/opt/vagrant/embedded/gems/gems/vagrant-2.4.9/lib deploy/vagrant/port_check_test.rb
closed port 9       -> in use (WRONG)
listening port 50329 -> in use (right)
exit=1
