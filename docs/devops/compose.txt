# Lesson 10 extra part (DevOps), Task 4: albums + PostgreSQL in Docker Compose inside the VM (2026-10-20).
# Every command is printed before its output. The stack was started with
# 'docker compose -f /app/docker-compose.yml up -d --build': postgres became healthy before the api started.
# Inside the VM the Compose project is 'app' (the directory of the compose file), hence app-api-1 / app_pgdata.
# The dev password is written as <dev password>; the token is cut to 24 characters.

$ vagrant ssh -c 'docker compose -f /app/docker-compose.yml ps --format "table {{.Name}}\t{{.Image}}\t{{.Status}}\t{{.Ports}}"'
