# Lesson 10 extra part (DevOps), Task 3: Docker Engine in the VM (2026-10-20). Every command is printed before its output.
# Installed by the Vagrant provisioner deploy/vagrant/docker-engine.sh from Docker's apt repository. Before it ran,
# 'vagrant ssh -c docker --version' printed 'bash: line 1: docker: command not found'. The provisioner below is
# the second run: it is idempotent and only reports what is installed.

==> default: Running provisioner: docker-engine (shell)...
