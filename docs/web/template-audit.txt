# Context of every dynamic value (html/template escapes each one for the context it lands in):
#   .Title .Artists .Genre .Label .ReleaseYear .Available .Total  -> text inside <td>: < > & " ' become entities
#   .User.Email .User.Role                                        -> text inside <span>
#   .Query                                                        -> the value="..." attribute of the search input: quotes and tags escaped
#   .ID                                                           -> id="album-N" and hx-delete="/web/albums/N": an int64 rendered as attribute text
#   .Error                                                        -> text inside <p class="error">
#   block "title"                                                 -> text inside <title>
# No template.HTML, template.JS, template.URL or template.HTMLAttr anywhere: database text and user input stay text.
